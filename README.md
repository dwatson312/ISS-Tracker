# ISS-Tracker

A real-time International Space Station (ISS) position tracker built with JavaScript and Leaflet.js.

Retrieves ISS coordinates and Unix timestamps through HTTPS GET requests to the [Where The ISS At API](https://wheretheiss.at/) every 5 seconds. Displays the ISS position on an interactive OpenStreetMap map.

**Live Demo:** https://dwatson312.github.io/ISS-Tracker/
